Superseded by the [Canva revision](../2026-10-canva/README.md). Use that set for upload.

Five upload-ready screenshots, ordered by filename, live in `screenshots/`.
Each is a full-bleed 1280 × 800 RGB PNG with no alpha channel.

1. Inventory search and comparison selection in the new tab.
2. Highlighted UPC shortcuts for copying, eBay prices, and PriceCharting.
3. Offer Calculator with a $400 projected sale and all four default offer types.
4. The iPhone companion app alongside Chrome's scanner history.
5. Store details and a masked login in the Handbook.

`chrome-web-store-screenshots.zip` contains only the five final images.
`contact-sheet.png` provides an overview. `gallery.html` previews the set.
Each numbered HTML file is an editable, local layout. Edit `render.mjs` to
change typography, copy, framing, and crops, then run it again.

## Sources and fidelity

Captured with Playwright on October 25, 2026. The UI was not generated by AI.
Inventory, UPC, scanner history, and handbook use real extension components
with the repository's existing sample-data preview scenarios from commit
`b6c0cc8a`, also the source for release 1.0.80. This root checkout was behind
that source; the source was read from the existing checkout at
`/Users/juanquenga/.t3/worktrees/Volt/t3-a164ce51`.

The calculator was captured from the downloaded v1.0.80 release package in
an isolated Chromium extension profile, using its default calculation rules.
Its header was cropped to focus on the calculation. No sign-in was needed.

The existing iPhone image is
`apps/web/public/assets/app-screenshots/barcode-detected.webp`; it includes
its original phone frame. The companion image and scanner history show
independent example captures, not a recorded end-to-end transfer.
Scanner cards and handbook are cropped for focus. The neutral window bars
are presentation frames added around the captures, not extension controls.
All shown inventory, store information, and capture history are sample data.
No account credentials, live customer information, or actual shop data are used.

Only the reusable abstract backdrop was generated with the built-in imagegen
tool. Its full prompt is in `sources/background-prompt.txt`; the generated
image is preserved as `sources/background.png`. No Canva design was created.

## Reproduce

Use a checkout containing the extension's `preview/` workflow. Start its
preview server on a free port, for example:

```sh
pnpm --filter @volt/extension preview --host 127.0.0.1 --port 5198
```

From this directory, with dependencies already installed:

```sh
node capture.mjs http://127.0.0.1:5198 /absolute/path/to/unpacked-v1.0.80
node render.mjs
```

The release argument is optional; omitting it preserves the existing calculator
capture. `CHROME_EXECUTABLE` optionally selects Chrome for Testing. Capture
profiles are isolated. Mobile and generated background sources are retained
rather than regenerated. Rendering requires no development server or build.
